Previews and case studies

The tick. Marking a project live moves its card into Launched on the public previews page straight away. Nothing is rebuilt and nothing is pushed, the page reads this database when it loads.

Reissuing a passphrase. New passphrase makes one up and puts it live on the preview and its project sheet together. Use what I typed does the same with your own wording. Either way the old passphrase stops working, so send the new one on before you close this page. It checks the key against the live file first, so a failure changes nothing.

The one gap worth knowing: if Supabase is ever down, the preview falls back to the passphrase it was originally built with, so a client is never locked out of their own page by an outage. If you need a passphrase properly dead rather than superseded, say so and the file gets rebuilt.
